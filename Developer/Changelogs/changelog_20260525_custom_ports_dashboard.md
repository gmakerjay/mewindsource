## 1. การเปลี่ยนแปลงและเพิ่มฟีเจอร์หลัก (Key Highlights)

### 1.1 การปรับปรุงแผงควบคุมระบบ Cockpit (Frontend Overhaul)
*   **[MODIFY] [dashboard.html](file:///c:/Users/admin/Documents/EDOTh/WindBot_Sandbox/templates/dashboard.html):**
    *   **การตั้งค่าพอร์ตอิสระ (7911-7999):** เพิ่มช่องกรอก Input ตัวเลข `port-input` ที่ให้ผู้ใช้กรอกพอร์ตจำลองได้เองอย่างอิสระระหว่าง `7911` ถึง `7999` (ค่าเริ่มต้นคือ `7911`) เมื่อเลือกใช้งานโหมดจำลองการดวลจริง (Live Duel Simulator)
    *   **การเลือกจำนวนบอทต่อห้อง (1 หรือ 2 ตัว):** เพิ่ม Dropdown `bot-count-select` เพื่อให้ผู้ใช้สามารถเลือกว่าต้องการดวลกับบอทด้วยตัวเอง (1 ตัว) หรือให้บอทแข่งกันเองแล้วเราทำหน้าที่สังเกตการณ์ (2 ตัว)
    *   **ปลดล็อกการเลือกเด็คบอท:** ปรับปรุงปุ่มและรายการดึงข้อมูลจาก API `/api/decks` ให้ดึงข้อมูลเด็คทั้งหมดในโฟลเดอร์ออกมาแสดงผลโดยไม่มีการฟิลเตอร์เฉพาะเด็ค `2026_` เพื่อให้นำเด็คอื่นมาร่วมดวลจำลองได้เต็มที่
    *   **การส่งพารามิเตอร์การดวล:** อัปเดตฟังก์ชัน JavaScript `startTraining()` ให้ทำการอ่านค่า `port` และ `bot_count` จากหน้าจอเพื่อแนบไปกับคำขอ POST `/api/train`

### 1.2 การปรับปรุงหลังบ้านของระบบ Cockpit (Backend Updates)
*   **[MODIFY] [cockpit.py](file:///c:/Users/admin/Documents/EDOTh/WindBot_Sandbox/cockpit.py):**
    *   **รับพารามิเตอร์ใหม่:** ปรับปรุงส่วนประมวลผล `/api/train` และฟังก์ชัน `start_training()` เพื่อให้รับค่า `port` และ `bot_count` จากคำร้องขอ POST ของผู้ใช้งาน
    *   **สลับพฤติกรรมการรันบอท (1 หรือ 2 ตัว):** ปรับปรุงฟังก์ชัน `run_live_duel_loop()` เพื่อให้รองรับกรณี `bot_count == 1` โดยจะทำการสร้างและรันบอทหลักเพียงตัวเดียว (`p1: IgnisBot`) บนพอร์ตที่เลือก และเฝ้าคอยจนกว่าโปรเซสของบอทหลักจะยุติลง (เปิดโอกาสให้ผู้เล่นสามารถใช้โปรแกรม EDOPro โฮสต์ห้องและเชื่อมเข้ามาดวลได้อย่างสะดวก)
    *   **ระบบวนลูปพอร์ตคงที่ (Fix Port Loop):** รองรับระบบวนรอบ (Loop) ดวลซ้ำหลายๆ ตาบนพอร์ตคงที่ตามที่ผู้ใช้กำหนด (Fix Port) โดยผู้ใช้ไม่ต้องเปลี่ยนหรือสลับพอร์ตในแต่ละตา

### 1.3 สารบบเด็คแชร์การใช้งาน (Shared Utilities Update)

## 2. วิธีการยืนยันและการตรวจสอบระบบ (Verification & Testing)
1.  เปิดระบบ Cockpit Dashboard: `python WindBot_Sandbox/cockpit.py`
2.  เปิดหน้าเว็บเบราว์เซอร์ เข้าแผงควบคุม
3.  เลือกประเภทโหมดเป็น **"จำลองการเล่นจริงผ่าน WindBot (Live Duel Simulator)"**
4.  กรอกพอร์ตที่กำหนด เช่น `7925` เลือกจำนวนบอทเป็น `1 ตัว` จากนั้นกดปุ่ม **"เริ่มการฝึกฝน"**
5.  ตรวจสอบคอนโซลและการบันทึก Log ว่ามีการ Spawn เฉพาะบอท `IgnisBot` ตัวเดียวเชื่อมต่อไปยังพอร์ต `7925` อย่างถูกต้อง และยอมรับให้ผู้ใช้เข้ามาร่วมดวลได้จริง
